# Referencias y recursos técnicos

Esta bibliografía respalda el contexto general de sensores agrícolas, medición de humedad y plataforma embebida. Las publicaciones citadas no validan por sí mismas el sistema AGRO-TECH 5.0.

## Plataforma embebida

1. **Espressif Systems.** *ESP32-S3 Series — Technical Documents and Datasheet.* Documentación oficial del fabricante. [Documentos técnicos](https://www.espressif.com/support/documents/technical-documents) · [ESP32-S3](https://www.espressif.com/en/products/socs/esp32-s3).

## Sensores agrícolas y humedad del suelo

2. **“Soil Moisture Sensing Technologies: Principles, Applications, and Challenges in Agriculture.”** *Agronomy*, 15(12), 2788 (2025). [DOI: 10.3390/agronomy15122788](https://doi.org/10.3390/agronomy15122788). Revisión de tecnologías invasivas y no invasivas, principios de medición, calibración y desafíos de aplicación.

3. **Faqir, Y.; Qayoom, A.; Erasmus, E.; Schutte-Smith, M.; Visser, H. G.** “A review on the application of advanced soil and plant sensors in the agriculture sector.” *Computers and Electronics in Agriculture*, 226 (2024), artículo 109385. [DOI: 10.1016/j.compag.2024.109385](https://doi.org/10.1016/j.compag.2024.109385). Revisión de tecnologías de sensores para plantas y suelo, incluidas señales ópticas, inalámbricas y eléctricas.

4. **“Advanced technologies of soil moisture monitoring in precision agriculture: A Review.”** *Smart Agricultural Technology* (2024). [Artículo en ScienceDirect](https://www.sciencedirect.com/science/article/pii/S2666154324005106). Revisión sobre tecnologías de seguimiento de humedad, sensores y sistemas basados en IoT.

5. **“A systematic review on soil moisture estimation using remote sensing data for agricultural applications.”** *Smart Agricultural Technology* (2025). [Artículo en ScienceDirect](https://www.sciencedirect.com/science/article/pii/S2666017225001348). Revisión de métodos ópticos, térmicos y de microondas para estimación de humedad del suelo mediante observación remota.

## Uso de las referencias

- Consultar la versión vigente de las hojas de datos antes de seleccionar componentes.
- No extrapolar la precisión de un sensor de una aplicación a otra sin calibración.
- Registrar la fecha de consulta y la versión documental utilizada en futuras revisiones.
- Incorporar artículos adicionales a medida que se concrete el cultivo, la variable objetivo y el método de ensayo.

**Criterio de integridad:** las referencias sustentan el contexto tecnológico; no deben citarse como evidencia de que AGRO-TECH 5.0 haya alcanzado resultados experimentales propios.
