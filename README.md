# AGRO-TECH 5.0

SQ-ONE Research Lab — investigación y desarrollo agrotecnológico.

Propuesta de arquitectura modular para integrar observación de la parte aérea de la planta (CANOPY / OPTO-TECH), mediciones de la zona radicular (ROOT / ELECTRO-TECH) y una capa digital de adquisición y trazabilidad (SOFHTECH 5.0). El ESP32-S3 se considera una plataforma embebida de referencia, sujeta a verificación técnica.

**Estado:** arquitectura conceptual en desarrollo. El prototipado integrado y la validación experimental y de campo permanecen como etapas pendientes. Este repositorio distingue las funciones propuestas de los resultados demostrados.
